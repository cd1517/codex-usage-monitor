# 原生附着与字号菜单设计

横条尾部增加省略号按钮，点击后显示 macOS 原生菜单，列出 `14pt` 到 `20pt` 七档字号，当前值带勾。选择后立即更新并写入本应用 `UserDefaults`；读取到缺失或越界值时回到 `18pt`。字号不只影响文字：通过纯函数生成紧凑横条和详情延伸的尺寸、行高、内边距与间距，字号越大，两个区域同步递增。闪电图标使用系统蓝色，省略号保持次要文字色。

悬停仍只使用一个透明、非激活 `NSPanel`。面板整体向左下方扩展，但紧凑横条固定在面板右上角，屏幕坐标和自身尺寸均不变化；详情背景从横条下方连续向左下方生长，形成阶梯形的一体轮廓，而不是把横条拉宽成新卡片。收起时详情反向缩回，横条全程不移动。省略号菜单打开期间暂停自动收起，菜单关闭后再根据真实鼠标位置决定是否收回。

窗口跟踪从“仅 ChatGPT 前台”改为“只要 ChatGPT 有可见主窗口就持续跟踪”。面板使用普通窗口层级；ChatGPT 激活时把面板排在其窗口上方，切换到其他应用时不隐藏、不置顶，因此其他正常窗口会自然覆盖它。ChatGPT 最小化、关闭、退出或没有可见主窗口时隐藏。测试覆盖字号钳制、默认值、各字号尺寸单调递增、主窗口后台持续选择和低余量颜色；实机验收覆盖菜单、设置记忆、横条固定、详情延伸、蓝色图标及跨应用遮挡关系。
