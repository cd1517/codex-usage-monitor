# 标题栏用量横条设计

用量显示改为 `220×30` 的单行横条，固定在 ChatGPT 标题栏“分享”按钮左侧。横条展示 `5小时 剩余百分比` 与 `7天 剩余百分比`，保留灰色系统闪电标识，并在最右侧用一条细竖线与“分享”按钮分隔；手动刷新与退出仍保留在菜单栏。横条不使用圆角卡片、异色描边、阴影或彩色图标底，背景采用 macOS 窗口背景色，文字使用与 ChatGPT 标题栏一致的系统字体和接近字号，使其在视觉上融入标题栏。

横条始终不透明，不提供透明度变化、拖动或位置记忆。鼠标悬停时，同一个面板保持顶部边缘和右边缘不变并向左下方展开，显示 5 小时与 7 天窗口的重置日期、可用重置额度，以及最早到期重置额度的截止有效期；移开后收回横条。面板继续使用 `.nonactivatingPanel`，保持 `canBecomeKey=false`、`canBecomeMain=false`，接收悬停事件但不激活应用、不抢走 ChatGPT 输入焦点。

应用不申请辅助功能权限，因此不读取“分享”按钮本身的控件坐标。横条依据已确认的 ChatGPT 标题栏布局，使用相对主窗口右边缘的固定保留宽度定位，并在窄窗口中钳制到窗口左侧安全边距。ChatGPT 窗口移动或换屏时，现有窗口跟踪器继续实时更新横条位置；切换到其他应用后立即隐藏。

纯几何测试覆盖标准窗口定位和窄窗口钳制，数据测试覆盖重置额度有效期；真实 UI 验收覆盖分享按钮左侧位置、右侧分隔线、不透明外观、悬停详情和切换应用隐藏。
