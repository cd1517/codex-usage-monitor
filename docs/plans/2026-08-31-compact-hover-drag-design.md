# 紧凑悬停与位置记忆设计

浮窗外框缩小为 `280×170`。内容继续保留套餐、5 小时/7 天剩余量、重置时间、更新时间与重置额度，但压缩图标、字体、行距和内边距，不删除用户已有信息。默认 `alphaValue` 为 `0.65`；鼠标进入浮窗时用短动画过渡到 `1.0`，离开后回到 `0.65`。

浮窗从“不接收鼠标”改为可接收鼠标事件，但仍使用 `.nonactivatingPanel`，并保持 `canBecomeKey=false`、`canBecomeMain=false`，因此拖动和悬停不会激活本应用，也不会抢走 ChatGPT 输入焦点。内容区域没有按钮，任意位置按住鼠标即可拖动。

记忆位置采用 ChatGPT 主窗口内部的归一化坐标：横纵坐标分别表示浮窗在可用移动区域中的 `0...1` 比例。拖动结束时将比例写入本应用的 `UserDefaults`；ChatGPT 窗口移动、缩放或换屏幕后，按相同比例恢复。所有拖动和恢复结果都钳制在 ChatGPT 窗口内侧 `12pt` 范围，避免浮窗丢失。首次运行或没有有效保存值时仍使用原来的右上角默认位置。

纯几何函数覆盖相对位置计算、恢复与越界钳制；真实 UI 验收覆盖默认半透明、悬停变为不透明、拖动后隐藏/重新显示仍保持位置，以及切换到其他应用立即隐藏。
